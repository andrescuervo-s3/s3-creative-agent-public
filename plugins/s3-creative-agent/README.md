# S3 Creative Agent

Studio 3 Marketing's creative toolkit for [Cowork](https://claude.com/product/cowork).

## Skills

| Skill | Description |
|---|---|
| `s3-brief-selector` | Routes ambiguous "brief" requests to the correct S3 brief skill |
| `s3-foundational-brief` | Produce a structured, fact-based Foundational Brief for new clients from uploaded intake documents and web research |
| `s3-creative-brief-website` | Produce a project-specific creative brief for website design, redesign, or development projects |
| `s3-creative-brief-media` | Produce a project-specific creative brief for media planning, buying, or strategy projects |
| `s3-creative-brief-paid-ads` | Produce a project-specific creative brief for paid advertising campaigns |
| `s3-creative-brief-social-media` | Produce a project-specific creative brief for social media strategy, content, or campaigns |
| `s3-recommendation-doc` | Produce polished B&W internal recommendation documents for client strategy discussions |

## How Briefs Work

Studio 3 produces two types of briefs:

**Foundational Brief** — An evergreen, fact-based onboarding document created when a new client comes on board. Say "foundational brief," "client brief," or upload client intake documents and ask for a brief.

**Creative Brief** — A project-specific brief created when work begins on a deliverable. Four subtypes: Website, Media, Paid Ads, Social Media. Say the specific type (e.g., "website brief") or just say "creative brief" and the Brief Selector will ask which type you need.

If you just say "brief" without specifying, the Brief Selector will ask whether you need a Foundational Brief or a Creative Brief.

## Recommendation Documents

**Recommendation Doc** — A short (2–6 page) internal strategy document prepared before a client call or meeting. Presents a clear position on a client request: what we recommend, why, and what the approach looks like. Written for account managers in plain language, with an optional technical appendix for the dev team. Uses the shared S3 monochrome style system. Say "recommendation doc," "write up a recommendation for [client]," or "prepare a doc for the call."

Recommendation docs are separate from briefs — they are not routed through the Brief Selector.
